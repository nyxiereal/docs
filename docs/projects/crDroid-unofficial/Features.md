# Features that differ from base crDroid

## ROM

- Vanilla only (PLEASE don't flash GApps)
- Axion's sandbox app removed (useless)
- No MiCamera (couldn't get it to work yet)
- No MiGallery (why did you ever include it keosh...)

## Kernel

- Non-root by default (you can use KernelSU or wksu to root your phone)
- No SUSFS (not needed, use treatwheel+rezygisk)
- Applied Droidspaces-OSS patches
